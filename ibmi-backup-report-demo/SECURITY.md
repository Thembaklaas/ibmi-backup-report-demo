# Security and publication notes

- This repository uses generic demo identifiers and a non-deliverable example email address.
- Do not add hostnames, IP addresses, user IDs, real email addresses, internal library names, production control groups, tape volume IDs, job logs, or unredacted reports.
- Keep credentials and connection details out of source control. Use approved secret-management and deployment procedures.
- Inspect PDF metadata and all generated artifacts before publishing.
- If sensitive information was ever committed, remove it from Git history and rotate/revoke affected credentials where applicable.
- The demo report contains synthetic values and is not evidence of a real backup run.
